# Phrases to cut

Cut these, or rewrite the sentence so it doesn't need them.

## Throat-clearing openers

| Cut | Instead |
|---|---|
| "In this guide/page/section, you'll learn..." | Start with the first fact. |
| "Let's take a look at...", "Let's..." | State the thing. |
| "Here's what/how/why..." | Say it. |
| "It's worth noting that...", "Note that...", "Keep in mind that..." | The fact itself, or a `:::note`. |
| "It's important to...", "Make sure to..." | The instruction in the imperative: "Set `APP_URL` to..." |
| "As mentioned above/earlier...", "As we saw..." | Link to the section, or repeat nothing. |
| "Below, you'll find...", "The rest of this page..." | Delete. |
| "In order to..." | "To..." |
| "Basically", "Essentially", "Simply put" | Delete. |
| "Please" | Delete. |

## Emphasis crutches and adverbs

Delete these, or replace them with the fact they stand in for:

- just, simply, really, very, quite, truly, actually, basically, essentially, literally
- easily, quickly, seamlessly, effortlessly, automatically (say who does it: "Umpteenth retries it")
- obviously, clearly, of course, naturally, certainly
- fully, completely, entirely, totally, extremely, highly, incredibly
- significantly, dramatically, massively (give the number)
- typically, usually, generally, often, normally (give the condition: "for jobs without side effects")
- currently (the docs describe the current version)
- also and still, where they add nothing

Adverbs that carry a technical fact stay: "only", "at most", "at least", "once", "never" when the code guarantees it.

## Softeners

| Cut | Instead |
|---|---|
| "You might want to...", "You may wish to...", "Consider..." | "Set...", "Use...", or the condition: "For several replicas, set..." |
| "This could potentially..." | What it does, and when. |
| "Should work", "should be able to" | What happens. |
| "A bit", "somewhat", "fairly", "relatively" | The measure, or nothing. |

## Hype

- powerful, robust, seamless, blazing fast, cutting-edge, game-changing, best-in-class
- "unlock", "supercharge", "empower", "leverage" (use "use")
- "a wide range of", "a variety of" (list two examples)
- "the magic of", "under the hood" (explain the mechanism, or leave it out)

## Vague declaratives

| Cut | Instead |
|---|---|
| "This matters." | Say what breaks without it. |
| "The implications are significant." | Name the implication. |
| "This is where X comes in." | "X does Y." |
| "There are several reasons for this." | Give the reason. |
